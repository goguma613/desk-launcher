# 바탕화면 런처 위젯

자주 쓰는 프로그램 · 폴더 · 파일 · 웹링크를 한곳에 모아 클릭 한 번으로 실행하는
Windows 데스크톱 위젯입니다. Tauri 2 + Vue 3.

## 실행

개발 모드로 띄우기:

```bash
npm run tauri dev
```

설치 파일 만들기:

```bash
npm run tauri build
```

결과물은 `src-tauri/target/release/bundle/nsis/` 아래에 `.exe` 설치 파일로 나옵니다.

### 반드시 일반 권한 터미널에서

관리자 권한 터미널에서 실행하면 앱도 관리자 권한으로 뜨고, 그러면 **일반 권한
탐색기에서 드래그앤드롭이 막힙니다.** 마우스 커서가 금지 표시로 바뀌며 파일이
놓이지 않습니다. Windows 보안 정책(UIPI)이라 코드로 우회할 수 없습니다.

## 쓰는 법

| 동작 | 방법 |
| --- | --- |
| 항목 추가 | 창 위로 파일 · 폴더 · 프로그램을 끌어다 놓기 |
| 웹링크 추가 | 편집 모드의 `+ 링크` 또는 빈 탭의 안내 버튼 |
| 실행 | 항목 클릭 |
| 삭제 · 순서 변경 · 이름 수정 | 연필 버튼으로 편집 모드 진입 |
| 이름 · 아이콘 수정 | 항목 우클릭 |
| 배치 · 모드 · 탭 · 단축키 변경 | 푸터의 톱니 버튼 — 별도 창으로 열립니다 |
| 창 위치 미세 조정 | 푸터 왼쪽 안내 문구를 끌기 |
| 창 켜고 끄기 | 전역 단축키 (기본 `Alt+Space`) 또는 트레이 아이콘 |
| 완전히 종료 | 트레이 우클릭 → 종료, 또는 설정 화면 맨 아래 |

창을 닫아도 종료되지 않고 트레이에 남습니다.

## 데이터

항목과 설정은 전부 파일 하나에 저장됩니다.

```
%APPDATA%\io.github.goguma613.desk-launcher\state.json
```

설정 화면의 `설정 파일 폴더 열기` 버튼으로 바로 갈 수 있습니다. 이 파일만
복사하면 다른 PC로 그대로 옮겨집니다. 사용자가 지정한 아이콘 이미지도 이 안에
들어 있어서 따로 챙길 것이 없습니다.

## 시안 적용 지점

시안 적용은 끝났습니다. 이후 시안이 수정되면 아래 네 군데만 손대면 됩니다.
기능 코드는 건드릴 필요가 없습니다.

| 파일 | 바꾸는 것 |
| --- | --- |
| `src/style.css` | 색 · 간격 · 모서리 · 그림자 · 폰트. 전부 CSS 변수로 모여 있습니다 |
| `src/icons.js` | 폴백 아이콘 8종의 SVG path |
| `src/layout.js` | 프리셋별 치수 상수 (셀 크기, 탭 바 · 푸터 높이, 여백) |
| `src/components/ItemGrid.vue` | 셀 내부 구성 (아이콘 크기 · 이름 줄 수) |

`layout.js`의 상수와 `ItemGrid.vue`의 `.tile` / `.name` 값은 한 세트입니다.
한쪽만 바꾸면 창 높이가 어긋나 마지막 행이 잘립니다.

컴포넌트별 `<style scoped>`는 구조만 잡고 값은 전부 위 변수를 참조합니다.

확정된 시안의 전체 스펙은 `docs/design-handoff.md`에 있습니다. 시안 토큰과 현재
`style.css` 변수의 매핑, 코드와 시안이 어긋나는 지점도 그 문서 끝에 표로
정리되어 있습니다.

### 폰트

시안이 지정한 Pretendard를 `public/fonts/PretendardVariable.woff2`로 함께
넣었습니다. SIL Open Font License 1.1이며 원문은 `public/fonts/OFL.txt`에 있습니다. 가변 폰트 한 벌이라 400 · 500 · 700을 이 파일 하나에서 씁니다.
네트워크 없이 동작하고, 파일이 없으면 맑은 고딕으로 떨어집니다.

## 구현 범위

- 항목 영구 저장, 삭제, 드래그 순서 변경
- 탭 추가 · 삭제 · 이름 변경 · 순서 변경 (최대 8개)
- 아이콘: 사용자 지정 이미지 → (웹링크는 파비콘 / 그 외는 Windows 실제 아이콘) →
  폴백 세트 8종 → 이름 첫 글자 순으로 적용
- 배치 프리셋 3종 (우측 세로 300px · 하단 가로 96px · 중앙 박스 720 × 520)
- 표시 모드 2종 (바탕화면 고정 · 오버레이)
- 설정 별도 창 560 × 680과 탭 편집, 전역 단축키 변경, 트레이 상주, 시작 시 자동 실행
- 다크 / 라이트 테마, 배경 불투명도 조절
- 경로가 사라진 항목 표시, 이름이 잘렸을 때 호버 툴팁

## 아는 제약

- **아이콘은 처음 한 번만 느립니다.** 탐색기가 쓰는 `IShellItemImageFactory`로
  뽑아 `%APPDATA%\io.github.goguma613.desk-launcher\icons\`에 96px PNG로 저장합니다.
  대상 파일의 수정 시각이 바뀌면 자동으로 다시 뽑고, 그래도 갱신이 안 되면
  설정 창의 `아이콘 새로 고침`을 쓰세요.
- **파비콘은 외부 요청입니다.** 먼저 사이트의 `/favicon.ico`를 시도하고, 실패하면
  구글 파비콘 서비스로 넘어갑니다. 이때 도메인 이름이 구글로 전달됩니다. 둘 다
  실패하면 기본 링크 아이콘으로 대체됩니다.
- **바탕화면 고정 모드는 완전한 "배경 붙박이"가 아닙니다.** 창을 클릭하면
  Windows가 잠깐 앞으로 끌어올리고, 앱이 곧바로 다시 맨 아래로 내립니다.
  아주 짧게 깜빡일 수 있습니다.
- **자동 실행은 현재 실행 파일의 경로를 기억합니다.** 빌드 폴더에서 직접 실행한
  상태로 자동 실행을 켰다가 나중에 설치 버전을 쓰면 경로가 어긋납니다. 설치한
  뒤에 설정에서 한 번 껐다 켜 주세요.

## 폴더를 옮길 때

`src-tauri/target`에 최초 컴파일 경로가 박혀 있어서, 폴더를 통째로 옮기면 빌드가
이전 경로를 찾다가 실패합니다. 옮긴 뒤 `target`을 지우고 다시 빌드하세요.

```bash
rm -rf src-tauri/target
```

재빌드에 5~15분 걸립니다. `target`은 빌드 산출물이라 지워도 소스에는 영향이
없습니다.
