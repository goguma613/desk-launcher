# 바탕화면 런처 위젯 — 개발 핸드오프

2026-09-20

## 개요

Windows 바탕화면에 상시 띄워두는 바로가기 런처입니다. 자주 쓰는 프로그램·폴더·파일·웹링크를 탭으로 묶어 한 번의 클릭으로 실행합니다.

스택은 **Tauri 2 + Vue 3**입니다. 화면이 HTML/CSS로 그려지므로 시안이 거의 그대로 구현됩니다.

사용 환경은 두 대입니다. 개인 PC가 QHD 2560 × 1440, 회사 PC가 FHD 1920 × 1080입니다. 세로가 360px 차이 나므로 세로 패널에서는 이 차이가 곧 몇 줄이 더 들어가느냐로 이어집니다. 작업 기준은 FHD입니다.

### 시안 단계에서 확정된 것

| 항목 | 결정 |
| --- | --- |
| 시각 방향 | 미니멀 격자 — 아이콘을 크게, 이름은 1줄, 여백 우선 |
| 기본 테마 | 다크. 라이트는 같은 토큰 이름을 덮어쓰는 방식으로 전환 |
| 배치 프리셋 | 우측 세로 패널(기본) · 하단 가로 바 · 중앙 박스 — 설정에서 하나 선택 |
| 표시 모드 | 바탕화면 고정 · 오버레이 — 레이아웃은 두 모드가 동일 |
| 아이콘 | Windows 실제 아이콘 **자동 추출을 구현 범위에 포함** |
| 서체 | Pretendard (웹폰트 무료) |

프로토타입으로 이미 검증된 동작은 네 가지입니다. 창 안으로 드래그앤드롭해 항목 등록, 클릭 시 프로그램·폴더·파일·URL 실행, 바탕화면 고정과 항상 위 전환, 전역 단축키로 창 켜고 끄기.

시안 캔버스는 Claude 아티팩트로 있습니다. 비공개이므로 담당자가 열려면 공유 설정이 필요합니다.

## 화면 구성과 치수

세 프리셋 모두 내부 구조는 같습니다. **탭 바 → 항목 격자 → 푸터** 순이고, 달라지는 것은 방향과 컬럼 수뿐입니다.

| 프리셋 | 치수 | 격자 | 셀·카드 | 한 화면 수용 |
| --- | --- | --- | --- | --- |
| 우측 세로 패널 | 폭 300px 고정, 우측 가장자리 밀착 | 3열 | 90 × 81px | FHD 27개 |
| 하단 가로 바 | 높이 96px, 폭 100%, 작업표시줄 위 8px | 1행 | 84 × 76px | 1920px에서 18개 |
| 중앙 박스 | 720 × 520px, 화면 정중앙 | 6열 | 105 × 96px | 24개 |

세로 패널은 상하 가장자리에 붙지 않고 **세로 중앙 정렬**입니다. 좌측 모서리만 둥글고(14px) 우측은 직각입니다.

### 세로 패널 내부 (기본 프리셋)

| 영역 | 높이 | 내용 |
| --- | --- | --- |
| 탭 바 | 41px | 탭 버튼(패딩 13 / 9 / 10) + 탭 추가 버튼, 아래 1px 구분선 |
| 항목 격자 | 가변 | 패딩 12 / 10, 격자 간격 4px |
| 푸터 | 45px | 항목 수 · 안내 문구 + 설정 버튼, 위에 1px 구분선 |

셀 하나는 세로로 쌓은 플렉스입니다. 패딩 10 / 4, 아이콘 40 × 40px, 간격 7px, 이름 11px(행간 1.3). 합치면 81px입니다.

아이콘 박스 크기는 프리셋별로 다릅니다. 세로 패널과 가로 바가 40px, 중앙 박스가 44px입니다.

탭은 초기값이 게임 / 유틸 / 브라우저 세 개이고, 8개까지 늘어난다고 보고 설계했습니다. 세로 패널에서 탭이 폭을 넘으면 탭 바만 가로 스크롤합니다.

## 해상도 확장 규칙

**폭은 고정, 높이만 항목 수에 따라 늘어납니다.** 해상도가 바뀐다고 셀이나 글자 크기를 키우지 않습니다. 들어가는 줄 수만 달라집니다.

최대 높이는 **화면 세로의 82%**입니다. FHD 885px, QHD 1180px. 이를 넘으면 항목 영역만 스크롤하고 탭 바와 푸터는 고정입니다.

| 항목 수 | 필요 높이 | FHD 표시 | QHD 표시 |
| --- | --- | --- | --- |
| 12개 | 447px | 12개 전부 | 12개 전부 |
| 21개 | 702px | 21개 전부 | 21개 전부 |
| 30개 | 956px | 27개 (3개 스크롤) | 30개 전부 |

FHD 기준 항목 영역은 885 − 41(탭 바) − 45(푸터) = **799px**이고, 여기에 81px 셀이 9행 들어갑니다. QHD는 1094px에 12행입니다. 한 화면에 3행(9개)을 더 담습니다.

구현 시에는 모니터 작업 영역(`availHeight`, 작업표시줄 제외)을 기준으로 82%를 계산하십시오. 전체 해상도를 쓰면 작업표시줄과 겹칩니다.

모니터를 옮기거나 해상도가 바뀌면 최대 높이를 다시 계산하고 패널 위치를 재정렬해야 합니다. Tauri의 디스플레이 변경 이벤트를 받아 처리하면 됩니다.

## 아이콘 처리

이 문서에서 구현 난이도가 있는 유일한 부분입니다. 처음에는 범위에서 제외했다가, 생각보다 비용이 크지 않아서 **포함하는 것으로 바뀌었습니다**.

### 적용 순서

위에서부터 순서대로 시도하고, 실패하면 다음으로 내려갑니다.

1. 사용자가 직접 지정한 이미지 — 언제나 1순위
2. 웹링크는 파비콘, 그 외에는 Windows에서 추출한 실제 아이콘
3. 종류별 기본 아이콘 (폴백 세트 8종)
4. 이름 첫 글자 — 종류도 판별하지 못했을 때

이 순서가 시각 규칙과 맞물려 있습니다. **추출된 실제 아이콘은 배경 박스 없이 그대로 얹고**, 폴백 아이콘만 `--bg-surface` 라운드 박스 안에 넣습니다. 실제 아이콘은 이미 자기 배경과 실루엣을 가지고 있어서 박스를 다시 씌우면 액자 안에 액자가 됩니다.

### 추출 구현

두 가지 길이 있습니다.

| 방식 | 최대 크기 | 작업량 | 비고 |
| --- | --- | --- | --- |
| [`systemicons`](https://docs.rs/systemicons) 크레이트 | 64px | 몇십 줄 | `get_icon(경로, 크기)` → PNG 바이트 |
| [`windows`](https://microsoft.github.io/windows-docs-rs/doc/windows/Win32/UI/Shell/fn.ExtractIconExW.html) 크레이트 + [`IShellItemImageFactory::GetImage`](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ishellitemimagefactory-getimage) | 256px | 100~150줄 | 탐색기가 쓰는 API. exe·폴더·.lnk·스토어 앱 모두 처리 |

**`IShellItemImageFactory` 쪽을 권합니다.** QHD에서 40px 박스에 64px 소스를 넣으면 흐릿합니다. 반나절에서 하루 정도 봅니다.

### 넣기 쉬운 함정 네 가지

- **알파 채널** — HICON/HBITMAP을 PNG로 바꿀 때 premultiplied alpha를 되돌리지 않으면 아이콘 가장자리에 검은 띠가 생깁니다. 가장 많이 걸리는 지점입니다.
- **캐시** — 추출한 PNG를 appdata에 저장하세요. 켜질 때마다 30개를 추출하면 시작이 느려집니다.
- **바로가기 파일** — 게임 런처는 .lnk가 `steam://rungameid/...` 같은 프로토콜을 가리키는 경우가 있습니다. 대상을 풀지 말고 **.lnk 경로를 그대로** 넘기면 알아서 처리됩니다.
- **캐시 무효화** — 대상 파일의 수정 시각(mtime)을 함께 저장하고, 바뀌었을 때만 다시 뽑습니다. 프로그램이 업데이트되면 아이콘도 바뀝니다.

### 폴백 아이콘 8종

실패했을 때만 나오므로 종류를 줄였습니다. 실행 파일, 폴더, 문서, 이미지, 웹링크, 게임, 도구, 기타.

사양은 24 × 24 viewBox, 스트로크 1.6px, 라운드 캡과 조인, 면 채움 없음, 색은 `currentColor`입니다. 박스 안 아이콘 크기는 40px 박스에 22px, 44px 박스에 24px입니다.

이름 첫 글자 폴백은 Pretendard Bold 18px, 한글 1자 또는 영문 1자 대문자입니다.

## 이름 표시와 말줄임

항목 이름은 Windows 파일명을 그대로 가져오므로 길이를 예측할 수 없습니다. 규칙을 정해두었습니다.

표시 이름에서 **확장자는 지우고**(.exe · .lnk · .url) 원본 경로는 그대로 보관합니다.

자르는 방향이 둘로 나뉩니다. **파일명은 끝 말줄임**, **경로는 앞 말줄임**입니다. 경로는 뒤쪽이 정보라 `…\Steam` 처럼 앞을 잘라야 쓸모가 있습니다.

| 프리셋 | 줄 수 | 최대 폭 | 11px 기준 글자 수 |
| --- | --- | --- | --- |
| 세로 패널 | 1줄 | 78px | 한글 6자 · 영문 12자 |
| 가로 바 | 1줄 | 76px | 한글 6자 · 영문 12자 |
| 중앙 박스 | 1줄 | 92px | 한글 7자 · 영문 15자 |

1줄 말줄임은 `white-space: nowrap` + `overflow: hidden` + `text-overflow: ellipsis` 조합입니다. 2줄이 필요한 곳이 생기면 `-webkit-line-clamp: 2`를 씁니다.

잘린 항목은 **0.6초 호버 뒤 전체 이름 툴팁**을 띄우고, 우클릭 → 이름 바꾸기로 고친 값은 항상 원본보다 우선합니다. 사용자가 고친 이름은 대상 파일이 바뀌어도 유지됩니다.

설정에 「항목 이름 표시」 토글이 있습니다. 끄면 아이콘만 남고 셀 높이가 81px에서 60px로 줄어듭니다.

## 상태와 모션

원칙은 하나입니다. **밝기만 바꾸고 크기는 건드리지 않는다.** 상시 띄워두는 도구라 요소가 자꾸 움직이면 시야 가장자리에서 거슬립니다.

### 항목 5상태

| 상태 | 규칙 |
| --- | --- |
| 기본 | 셀 배경 없음, 이름 `--text-item` |
| 호버 | 셀 배경 `--bg-hover`, 라운드 10px, 이름 한 단계 밝게. 크기 변화 없음 |
| 누르는 중 | 셀 배경 `--bg-press`, **아이콘만** `scale(0.94)`. 이름은 고정 |
| 드래그 중 | 원래 자리는 점선 자국, 삽입 위치에 2px 액센트 세로선, 들린 카드는 −2° + 그림자 |
| 아이콘 없음 | 이름 첫 글자, Bold 18px, `--bg-surface` 박스 |

이름을 아이콘과 같이 줄이지 않는 게 핵심입니다. 한글 11px를 0.94배 하면 글자가 떨려 보입니다.

### 탭 3상태

활성은 `--text-strong` Bold에 2px 액센트 밑줄, 비활성은 `--text-muted` Medium에 밑줄 없음, 호버는 그 사이 밝기에 흰색 16% 밑줄입니다.

### 화면 3종

- **드롭 영역 활성화** — 파일을 창 위로 가져오면 항목 격자를 26%로 죽이고 그 위에 점선 드롭존을 올립니다. 패널 테두리도 액센트로 바뀌고 바깥에 4px 글로우가 붙습니다.
- **빈 탭** — 패널이 최소 높이로 줄어듭니다. 빈 탭인데 세로로 길게 남아 있으면 그게 더 허전해서입니다. 점선 박스 안에 안내 문구와 「직접 찾아보기」 버튼.
- **편집 모드** — 헤더가 바뀌면서 완료 버튼이 뜨고, 각 항목에 ✕ 배지와 점선 테두리가 붙습니다. 드래그와 삽입선은 평소 순서 변경과 같은 표현입니다.

✕ 배지는 시각적으로 18px이지만 **실제 히트 영역은 28px로 넓혀 주세요**. 40px 아이콘 바로 옆이라 오클릭 위험이 있습니다. `::before`로 투명 패딩을 주면 됩니다.

### 모션

| 전환 | 시간 |
| --- | --- |
| 호버 진입 / 이탈 | 120ms / 160ms |
| 누름 / 놓음 | 80ms / 120ms |
| 드래그 시작 | 140ms |
| 탭 전환 (밑줄 이동) | 160ms |
| 오버레이 등장·퇴장 | 140ms 페이드 + 2px 위로 |

이징은 전부 `cubic-bezier(.2,.8,.3,1)`입니다. 탭을 전환할 때 항목은 페이드만 하고 위치는 움직이지 않습니다.

## 설정 화면과 탭 편집

설정은 560 × 680px 별도 창입니다. 다섯 섹션이 한 화면에 들어가고, 변경은 저장 버튼 없이 바로 적용됩니다.

| 섹션 | 내용 |
| --- | --- |
| 배치 | 프리셋 3종 라디오 카드. 각각 미니 도식으로 형태를 보여줍니다 |
| 표시 모드 | 바탕화면 고정 / 오버레이 라디오 + 한 줄 설명 |
| 전역 단축키 | 키캡 표시 + 「변경」 버튼. 기본값 Alt + Space |
| 일반 | 시작 시 자동 실행 · 항목 이름 표시 · 라이트 테마 토글 |
| 탭 | 현재 탭 칩 목록 + 「탭 편집」 진입 |

### 표시 모드 두 가지의 창 동작

레이아웃은 동일하고 **창 레이어와 그림자만 달라집니다.**

- 바탕화면 고정 — 항상 맨 아래 레이어. 그림자 `0 18px 44px rgba(0,0,0,.45)`. 단축키 비활성
- 오버레이 — 항상 맨 위 레이어. 그림자 `0 28px 70px rgba(0,0,0,.55)`, 테두리 4% 밝게. 단축키로 켜고 끔

밝은 배경화면 위에서는 다크 패널의 그림자를 `rgba(22,28,38,.30)`으로 낮춰야 덜 무겁게 앉습니다. 시안에 비교용 두 장이 있습니다.

### 탭 편집

560 × 520px 서브 화면입니다. 행마다 드래그 핸들 · 이름 · 항목 수 · 삭제 버튼이 들어가고, 이름은 그 자리에서 바로 고칩니다.

제약은 세 가지입니다. 탭은 최대 8개, 이름은 한글 2~6자 권장(넘으면 탭 바에서 말줄임), 탭을 지우면 그 안의 항목도 함께 사라집니다.

마지막 탭은 삭제를 막아야 합니다. 탭이 하나도 없는 상태는 시안에 없고, 생기면 보여줄 화면도 없습니다.

## 디자인 토큰

이름은 역할 기준이라 값이 바뀌어도 이름은 그대로 씁니다. 라이트 테마는 `[data-theme="light"]`에서 같은 이름을 덮어씁니다.

| 토큰 | 다크 | 라이트 | 용도 |
| --- | --- | --- | --- |
| `--bg-panel` | rgba(20,22,26,.96) | rgba(252,252,253,.97) | 패널 배경 |
| `--bg-surface` | #22262D | #E9ECF0 | 폴백 아이콘 박스 |
| `--bg-hover` | rgba(255,255,255,.06) | rgba(0,0,0,.05) | 항목 호버 |
| `--bg-press` | rgba(255,255,255,.11) | rgba(0,0,0,.09) | 항목 누름 |
| `--text-strong` | #E9EBEE | #14171C | 활성 탭 · 창 제목 |
| `--text-item` | #B9BFC8 | #3D444E | 항목 이름 |
| `--text-muted` | #8E95A0 | #666D79 | 비활성 탭 · 보조 |
| `--text-faint` | #6E7683 | #6E7580 | 푸터 · 캡션 |
| `--accent` | #E0A458 | #B87A2E | 활성 탭 밑줄 · 강조 |
| `--accent-soft` | rgba(224,164,88,.14) | rgba(184,122,46,.12) | 선택된 카드 바탕 |

### 간격 · 모서리 · 그림자

간격은 4 · 7 · 10 · 12 · 14 · 18px입니다. 격자 4, 항목 내부 7, 패널 좌우 10, 격자 상하 12.

모서리는 항목 10 · 아이콘 10 · 폴백 박스 11 · 패널 14 · 중앙 박스 18 · 칩 999px입니다.

그림자는 세 종류입니다. 패널 `0 18px 44px rgba(0,0,0,.45)`, 오버레이 `0 28px 70px rgba(0,0,0,.55)`, 드래그 중인 카드 `0 12px 26px rgba(0,0,0,.55)`.

### 타이포

Pretendard 400 / 500 / 700을 씁니다. 탭 13(700·500), 항목 이름 11(400, 행간 1.3), 창 제목 13.5(700), 섹션 라벨 11(700, 자간 .1em), 캡션 11(400). 한글 제목류는 자간 −0.01em을 줍니다.

## 구현 순서와 주의사항

순서를 이렇게 잡으면 중간에 되돌리는 일이 적습니다.

1. 토큰을 CSS 변수로 먼저 깔고 시작합니다. 색을 직접 박아놓고 나중에 바꾸려면 두 배로 듭니다.
2. 세로 패널 하나를 정적으로 완성합니다. 나머지 프리셋 둘은 같은 셀과 탭 바를 재배치한 것입니다.
3. 아이콘 추출을 붙입니다. 이게 제일 불확실한 조각이라 레이아웃이 깔려 있을 때 붙여야 문제가 보입니다.
4. 상태와 모션, 그다음 드래그앤드롭과 편집 모드.
5. 설정 창과 탭 편집.
6. 라이트 테마는 마지막입니다. 토큰을 제대로 깔았으면 속성 하나 바꾸는 수준입니다.

### 시안대로 옮길 때 놓치기 쉬운 것

- [ ] 패널 높이를 고정값으로 박지 않기 — 항목 수에 따라 늘어나고 최대 높이에서만 스크롤합니다
- [ ] 최대 높이를 `availHeight` 기준으로 계산하기 — 전체 해상도를 쓰면 작업표시줄과 겹칩니다
- [ ] 누를 때 아이콘만 축소하고 이름은 고정하기
- [ ] 추출된 실제 아이콘에는 배경 박스를 씌우지 않기 — 폴백만 박스를 가집니다
- [ ] 알파 채널 premultiply 되돌리기 — 안 하면 아이콘 테두리가 검게 뜹니다
- [ ] ✕ 배지 히트 영역 28px로 넓히기 — 보이는 크기는 18px 그대로
- [ ] 경로는 앞 말줄임, 파일명은 끝 말줄임
- [ ] 탭 전환 시 항목 위치를 움직이지 않기 — 페이드만
- [ ] 밝은 배경화면에서 다크 패널 그림자 낮추기

### 아직 안 정한 것

아이콘 8종은 시안 안에 그려져 있고, 개별 SVG 파일로는 아직 안 뽑았습니다. 필요하면 따로 묶어 드립니다.

바탕화면 고정 모드의 기본 테마를 다크로 할지 라이트로 할지는 시안의 비교 두 장을 보고 정하면 됩니다.

## 이 저장소에 적용하기

기능 코드는 이미 완성되어 있습니다. 시안은 아래 네 파일에서만 반영합니다.

| 파일 | 바꾸는 것 |
| --- | --- |
| `src/style.css` | 색 · 간격 · 모서리 · 그림자 · 폰트 토큰 |
| `src/icons.js` | 기본 아이콘 세트 SVG path |
| `src/layout.js` | 프리셋별 치수 상수 |
| `src/components/ItemGrid.vue` | 타일 내부 구성 (아이콘 크기 · 이름 줄 수) |

`layout.js`의 상수와 `ItemGrid.vue`의 `.tile` / `.name` 값은 한 세트입니다. 한쪽만 바꾸면 창 높이가 어긋나 마지막 행이 잘립니다.

### 토큰 이름 매핑

`style.css`는 색을 rgb 채널만 변수에 담고 alpha는 사용처에서 붙입니다(`rgb(var(--tile) / var(--tile-alpha))`). **이 규칙을 유지하세요.** 위 표의 hex 값은 채널로 바꿔 넣으면 됩니다.

| 시안 토큰 | style.css 대응 | 비고 |
| --- | --- | --- |
| `--bg-panel` | `--panel` + `--panel-alpha` | alpha는 설정에서 조절되는 값 |
| `--bg-surface` | `--panel-raise` | 폴백 아이콘 박스에도 이걸 씀 |
| `--bg-hover` | `--tile` + `--tile-alpha-hover` | 시안은 0.06, 현재 0.105 |
| `--bg-press` | `--tile` + `--tile-alpha-active` | 시안은 0.11, 현재 0.17 |
| `--text-strong` | `--text` | 거의 동일 |
| `--text-item` | **없음 — 추가 필요** | 항목 이름 전용. `--text`와 `--text-dim` 사이 밝기 |
| `--text-muted` | `--text-dim` | 거의 동일 |
| `--text-faint` | `--text-faint` | 거의 동일 |
| `--accent` | `--accent` | 값 교체 (현재 파랑 → 앰버) |
| `--border` | `--line` + `--line-alpha` | |
| `--divider` | `--line` + 더 낮은 alpha | 별도 alpha 변수 하나 추가 |
| `--icon-fallback` | **없음 — 추가 필요** | 폴백 아이콘 스트로크 색 |
| `--drop-line` | **없음 — 추가 필요** | 드롭 영역 점선 |
| `--radius-item` | `--radius-tile` | 둘 다 10px, 그대로 |
| `--radius-panel` | `--radius-panel` | 둘 다 14px, 그대로 |
| `--shadow-panel` | `--shadow-panel` | 값 교체 (시안이 더 깊음) |
